# 箱根駅伝配車シミュレーター

箱根駅伝の応援に参加するサークルメンバーへの配車計画を自動生成するツールです。
Googleフォームで収集した参加者情報をもとに、OR-Tools CP-SATによる最適化で
1〜10区＋帰路の配車（レンタカーの台数・運転手・同乗者の割り当て）を計算します。

## 機能

- Googleフォームの回答スプレッドシートを、Google Cloudの認証設定なしで直接読み込み
- OR-Tools CP-SATによる配車最適化（レンタカー台数・車の乗り換え回数・ランナーの希望区間・
  山組（9・10区）の車両台数などを考慮したソフト制約付き）
- 結果を画面表示・Excelファイル（入力データ／区間別ランナー／区間別配車／個人別まとめの
  4シート）でダウンロード
- 追加の個人的な希望（「この人とこの人はできるだけ一緒にしたい／離したい」「運転区間数を
  指定の範囲に収めたい」など）をもとに、既存の配車結果を再調整する追加機能あり
  （UIから直接アクセスする方法は運用者にお問い合わせください）

## セットアップ

### 1. 依存ライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. アプリの起動

```bash
streamlit run app.py
```

Google Cloudの認証設定（サービスアカウント・`credentials.json`）は**不要**です。
スプレッドシートが「リンクを知っている全員が閲覧可」に共有されていれば、
そのまま読み込めます。結果をスプレッドシートに書き戻したい場合のみ、
サービスアカウント認証（`credentials.json`）が別途必要です。

### 3. Googleフォームの質問構成

以下の質問文（キーワードが含まれていれば列の順番は問いません）を含むフォームを作成してください。

| 質問文の例 | 形式 | 選択肢 |
|--------|------|--------|
| 名前 | 短文 | |
| 学年 | ラジオボタン | 1年生 / 2年生 / 3年生 / 4年生 / 5年生以上 |
| 走りたい区間を全て選んでください | チェックボックス | 1区〜10区 |
| 特に走りたい区間があれば選んでください（任意） | チェックボックス | 1区〜10区 |
| 何区間まで走れますか？ | プルダウン | 1〜10 |
| 普通自動車の運転ができますか？ | ラジオボタン | はい / いいえ |
| 8人乗りのバン（大型）の運転ができますか？ | ラジオボタン | はい / いいえ |
| 山道（箱根の山）の運転ができますか？ | ラジオボタン | はい / いいえ |
| 宿泊しますか？ | ラジオボタン | はい（宿泊する） / いいえ（日帰り） |
| 日帰りの方：何区の後に帰りますか？ | プルダウン（任意） | 1区〜10区 |

## ファイル構成

- `app.py` — Streamlit UI本体
- `logic/milp_allocator_v3.py` — CP-SATによる配車最適化エンジン（表シュミ本体）
- `logic/back_sim.py` — 表シュミの結果に追加の希望を反映する再調整エンジン
- `logic/car_pool.py` — 車種・定員などレンタカー候補の定義
- `data_io/` — スプレッドシート読み込み・Excel出力・結果の読み戻し
- `validator.py` — 配車結果の整合性チェック
- `models.py` — 参加者・配車のデータ構造

## 注意

`participants.csv` / `form_responses.csv` / `back_sim_config.json` など、実際の参加者名を
含むファイルは`.gitignore`で除外しています。動作確認用のサンプルは
`back_sim_config.example.json`を参照してください。
